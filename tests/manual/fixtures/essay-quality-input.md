# 가상 지원 자료

이 문서의 회사·경험·수치는 모두 테스트용 가상 자료다. 실제 지원서나 공통자료에 옮기지 않는다.

## 사용자 요청

취뽀하자로 아래 기존 자료를 사용해 자소서 초안을 작성해줘. 공고 조사와 문항 수집은 끝났어. 확인된 사실만 사용하고 내 확인이 필요한 부분만 질문해줘. 실제 서비스 접속이나 외부 저장은 필요 없어. 각 문항은 소제목을 포함해 700자 이내로 작성해줘.

## 지원 건

- 회사: 가상회사 모아업무
- 직무: 업무 자동화 개발자
- 업무: 현업의 반복 작업 파악, 자동화 구현, 결과 검증과 운영
- 형식: 정중한 서술식. 소제목 허용. 공백과 LF 줄바꿈 포함 문자 수.

## 문항

1. 높은 수준의 목표를 스스로 설정하고 성취한 경험을 설명해주세요.
2. 직무를 위해 준비한 경험과 입사 후 기여하고 싶은 방향을 설명해주세요.
3. 직장을 선택하는 기준과 지향하는 조직을 설명해주세요.

## 확인된 개인 사실

### F1. 회의 녹화 기능 시험

- 참가자 식별자 12개를 사용한 8분 브라우저 시험에서 원본 트랙 16개 생성과 합성을 확인했다. 물리 장비 12대나 실제 고객 운영 기록은 아니다.
- 처음 검토한 24개 연결 시험은 일정 때문에 후속 과제로 남겼다.
- 요구사항에 따라 참가자 카메라는 저장하지 않고 음성과 발표 화면을 합쳤다.
- 담당 업무는 시험 구성과 결과 확인이다.
- 본인이 목표를 정한 경위, 이전에 가능한 수준, 목표를 높인 이유는 현재 자료에 없다.

### F2. 회의 내용의 잘못된 문자 변환 수정

- 조용한 구간에 음성 인식 모델이 실제로 말하지 않은 문장을 생성했다. 이 글이 회의 요약의 입력으로 쓰였다.
- 본인은 실제 녹음과 변환된 글, 코드를 AI 코딩 도구에 제공하고 잘못 생성된 문장을 제거하도록 요청했다.
- AI 코딩 도구는 무음 점수 0.75 이상인 구간을 제거하는 기준을 제안했다.
- 다른 녹음에 적용하고 원본과 대조하니 실제 발언 약 50초에 해당하는 글도 빠졌다. 녹음 파일 자체가 삭제된 것은 아니다.
- 본인은 해당 기준을 중지하고 반복 문장을 우선 판별하도록 변경을 지시했다. 확인한 정상 녹음 4건에서는 실제 발언 누락이 없었고, 앞서 빠진 글도 복구했다.
- 원본 변환 결과를 보관해 같은 AI 호출을 반복하지 않고 필터를 다시 적용할 수 있도록 했다.
- 확인 범위를 넘어 모든 인식 오류를 해결했다는 자료는 없다.

### F3. 개인 게시판의 글 갱신 자동화

- 기존에는 글 하나를 고칠 때도 프로그램 전체를 빌드하고 배포해야 했다.
- 본인은 내용 변경과 프로그램 변경의 처리 경로를 분리했다.
- 내용만 바꾸면 데이터베이스·파일·캐시를 갱신하고, 프로그램 코드 변경 때만 전체 배포를 실행하도록 했다.
- 한 번의 갱신에서 38초 뒤 새 요청에 변경이 반영된 것을 확인했다. 이전 시간, 평균 시간, 절감률은 측정하지 않았다.
- 직접 확인한 변화는 글 수정 시 전체 프로그램 배포가 필요 없어졌다는 것이다.

### 미확인 사항

- 직장 선택 기준과 지향하는 조직은 아직 기록하지 않았다.
- 광고 업계 경력이나 특정 자동화 언어의 숙련도를 확인한 자료는 없다.
