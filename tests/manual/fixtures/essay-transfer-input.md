# 다른 업무에서의 작성 평가용 가상 자료

회사와 경험은 모두 가상이다. 외부 서비스나 실제 취업 자료에 저장하지 않는다.

## 요청

취뽀하자로 아래 지원 건의 자소서 초안을 작성해줘. 조사와 문항 수집은 끝났어. 문항별로 소제목·공백·LF 줄바꿈 포함 800자 이내, 정중한 서술식으로 작성해줘. 확인된 사실만 사용하고 부족한 사실에 대한 질문은 결과에 남겨줘.

회사: 가상회사 누리운영. 직무: 내부 업무 도구 개발 및 운영 개선.

## 문항

1. 복합적인 제약을 해결하기 위해 목표를 정하고 달성한 경험을 설명해주세요.
2. AI를 업무에 활용한 경험에서 AI와 본인이 각각 맡은 일, 결과를 설명해주세요.
3. 데이터 처리 역량과 이해관계자 조율 역량을 각각 어떻게 준비했는지 설명해주세요.
4. 반복되는 업무를 개선한 경험을 설명해주세요.

## 사실 자료

### A. 공유 장비에서 자료 검색과 영상 변환 제공

- 검색과 영상 변환은 각각 실행되고 있었다. 본인은 추가 장비를 살 수 없는 예산 조건에서 한 장비로 두 기능을 제공하겠다는 목표를 정했다.
- 영상 변환은 계산 자원을 많이 사용한다. 변환 중 검색이 늦어질 수 있어서 본인이 동시 실행 시험을 구성했다.
- 첫 시험은 요청 생성 프로그램의 파일 경로 오류로 중단됐다. 경로를 수정한 뒤, 변환 두 건을 동시에 실행할 때 검색 응답이 최대 7초로 늘어남을 확인했다.
- 사용자들은 변환은 기다려도 되지만 검색은 바로 쓰고 싶다고 말했다. 본인이 변환을 한 건씩 처리하고 나머지는 대기시키도록 수정했다.
- 동일한 조건에서 검색 응답은 1.5초 이내였고 요청한 변환도 모두 끝났다. 동시에 검색 요청 6개를 보낸 4분 시험의 결과이며 전체 최대 용량은 측정하지 않았다.
- 본인은 장비의 상태 화면 색상과 로그 파일명도 바꿨다. 이 변경이 응답 속도를 높였다는 자료는 없다.

### B. AI가 제안한 문의 답변의 검토

- 운영 담당자는 내부 규정을 찾아 직원 문의에 답하고 있었다. 본인은 규정 원문을 검색해 AI에 제공하고 답변 초안과 근거 문단을 제안하게 하는 도구를 구현했다.
- 개정 전 규정과 새 규정이 함께 검색됐을 때 AI가 예전 규정으로 답하는 오류를 발견했다.
- 본인은 검색 대상을 현재 적용되는 규정으로 제한하고, 근거가 없으면 자동 답변 대신 담당자 확인으로 보내도록 수정했다.
- 담당자가 확인한 시험 문의 18건 중 근거가 있는 14건은 현행 규정과 일치했고, 근거가 없는 4건은 확인 목록으로 전달됐다. 실제 사용자에게 자동 발송하지 않았다.
- 사용 시간 절감률이나 모든 문의에 대한 정확도는 측정하지 않았다.

### C. 사내 행사 신청 정보 정리

- 참가자가 신청 폼에 연락 정보를 쓰고, 운영자가 같은 내용을 안내 명단에 다시 입력했다.
- 본인은 신청 응답으로 안내 명단을 생성하도록 연결했다. 잘못된 입력은 원본 신청 정보에서 고치면 명단에도 반영되도록 했다.
- 담당자는 안내 명단에 같은 정보를 다시 입력할 필요가 없어졌다고 확인했다.
- AI는 사용하지 않았으며 절감 시간과 오류 감소율은 측정하지 않았다.

### D. 주문 파일의 데이터 처리 연습

- 여러 점포의 주문 파일에서 날짜 형식과 상품 코드 표기가 달라 합산이 되지 않았다.
- 본인은 Python으로 날짜·상품 코드를 공통 형식으로 변환하고, 변환할 수 없는 행은 별도 파일로 분리했다.
- 변환 전후 주문 금액 합계를 대조해 유효 행의 금액이 보존됨을 확인했다. 매출 증가나 처리 속도 개선을 측정하지 않았다.
- 이 작업에 다른 부서와 의견을 조율한 경험은 없다.

### E. 인수인계 방식 조율

- 운영팀은 긴 인수인계 문서를 읽기 어렵다고 했고, 개발팀은 장애 재현 정보가 없으면 대응하기 어렵다고 했다.
- 본인은 양쪽이 실제 사용하는 문서를 함께 보며 필요한 정보를 확인했다. 앞부분에는 담당자·현재 상태·다음 행동을, 뒤에는 재현 절차와 상세 로그 링크를 배치하는 방식을 제안했다.
- 두 팀의 피드백을 반영해 긴 설명은 상세 링크로 옮겼다. 두 팀은 수정된 문서 형식을 함께 사용하기로 합의했다.
- 대응 시간이나 장애 감소율은 측정하지 않았다. 이 경험에 데이터 변환 코드를 구현한 사실은 없다.
