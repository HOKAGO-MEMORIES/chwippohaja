# 재검토용 가상 자료

회사·사건·수치는 모두 가상이다. 실제 개인 자료나 외부 서비스를 사용하지 않는다.

## 사용자 요청

취뽀하자 스킬로 아래 자소서 후보 두 개를 각각 검토해줘. 문항에 잘 답하고 처음 읽는 사람도 이해할 수 있는지 봐줘. 필요한 수정이 있으면 근거와 수정안을 제시해줘. 기존 검토 기록도 첨부했어. 파일이 필요하면 임시 작업 폴더만 사용해줘.

회사: 가상회사 모아행사. 직무: 행사 신청 서비스 개발 및 운영.
문항: 본인과 다른 의견을 가진 사람과 소통하여 의견을 조율한 경험을 설명해주세요. 분량 제한 없음.

## 확인된 경험 기록

행사 신청의 중복 접수를 정리하는 기능을 만들었다. 같은 사람이 여러 번 신청한 경우는 정리하되, 서로 다른 사람의 신청을 취소해서는 안 됐다.

- 본인은 시스템이 계산한 중복 점수가 높은 신청을 자동 취소하는 안을 제안했다. 표본을 확대하자 정상 신청도 취소됐고, 본인은 이 점수 기준을 철회했다.
- 본인은 이름이 같은 신청을 자동으로 합치는 안도 제안했다. 동료는 같은 이름을 가진 다른 신청자 두 명의 사례를 보여주며, 이름만 같으면 자동으로 합치지 말고 담당자가 확인하자고 제안했다.
- 본인은 동료와 해당 신청의 연락처를 대조해 서로 다른 사람임을 확인했다. 이름 일치만으로 자동 처리하자는 의견을 거두고, 이름은 같지만 연락처가 다른 신청은 확인 목록으로 보내자는 수정안을 제시했다. 동료도 동의했다.
- 수정한 이름 기준을 적용한 시험에서 동명이인 신청은 자동 취소되지 않고 확인 목록으로 전달됐다. 실제 행사 전체의 오류율은 측정하지 않았다.
- 점수 기준의 철회와 이름 기준의 논의는 위와 같이 기록돼 있다. 점수 계산에 사용된 항목과 두 논의 사이의 선후관계는 남아 있지 않다.

## 후보 A

[반례를 받아들여 바꾼 신청 정리 기준]
행사 중복 신청을 정리하며 동료와 기준을 조율했습니다. 저는 중복 점수가 높은 신청을 자동 취소하자고 제안했습니다. 한편 동료는 동명이인 두 명의 사례를 보여주며 이름만 같은 신청은 담당자가 확인하자고 했습니다.

정상 신청이 취소되는지 표본을 넓혀 확인하자 초기 점수 기준에 문제가 있었습니다. 저는 초기 제안을 철회하고 이름은 같지만 연락처가 다른 신청을 확인 목록으로 보내는 기준에 합의했습니다. 시험에서 동명이인 신청은 자동 취소되지 않았습니다. 상대의 반례를 확인해 제 의견을 수정한 경험입니다.

### 기존 검토 기록

문항 적합성과 인과관계 확인 완료. 동료의 동명이인 반례를 받아 중복 점수 기준을 철회하고 확인 목록으로 보내는 데 합의했다. 미해결 내용 문제 없음.
