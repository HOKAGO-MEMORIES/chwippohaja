# 제한된 입력의 최초 독자 검토 시험

- 기준 커밋: 9ef54ca. 검토 흐름 수정 후 로컬 미커밋 문서로 수행.
- 방식: 대화 이력을 상속하지 않는 새 하위 에이전트. 문항·본문·분량 조건과 독자 기준만 제공. 기존 설계·사실 원본·검토 결과·예상 판정은 제외.
- 실제 지원 초안과 개인 검토 원문은 공개 저장소 밖에 보관. 본문 변경 없이 동일 입력 사용.
- 자동 계약 테스트 119개 통과, skill-creator 기본 검증 통과. 이는 의미 검토 성능을 증명하지 않는다.

## 최초 수정안

실제 초안 2회, 가상 대조 사례 1회 검토했다. 실제 초안은 한 실행에서 시험 방식 전환의 설명 부족을 지적했으나, 평가자가 예상한 시험 목적 연결 및 후반 사례 연결의 문제를 일관되게 발견하지 못했다. 두 실행 모두 후반 사례를 충분하다고 판단했다.

경험형 답변 전체에 미래 활용을 요구하는 기존 지침 때문에 직접 문항을 충족한 실제 답변과 정상 대조 사례에도 권장 이슈가 발생했다. 이는 입력 격리만으로 지침 충돌이 해결되지 않음을 보여준다.

## 충돌 정리 후 최종 수정안

활용을 직접 묻지 않는 문항에서 배움·판단 기준이 충분하면 미래 업무 문장의 부재만으로 이슈를 만들지 않도록 기존 의무를 축소했다. 특정 사례의 결함 단서는 추가하지 않았다. 새 에이전트 2개로 실제 초안과 가상 대조 사례를 각각 1회 검토했다.

- 가상 대조: 목표·학습·조율의 근거가 부족한 A 3개를 지적하고 충분한 B 3개와 C 1개는 인정했다. 불필요한 미래 활용 요구는 사라졌다.
- 실제 초안: 5문항 모두 충분하다고 판정했다. 사전에 예상한 두 연결 문제는 이슈로 남기지 않았다. 이는 평가자의 예상 지적이 재현되지 않았다는 관찰이며, 확정된 결함의 검출 실패라는 뜻은 아니다.

## 해석과 한계

본문과 독자 판단을 다시 대조하여 평가자의 초기 지적을 정정했다. 첫 답변은 복합 제약과 설계·협업·시험으로 문항에 답한다. 시험 자체가 별개 경험이라는 지적은 과했고, 시험 방식의 전환이 앞선 도구 문제를 어떻게 해결하는지의 설명은 국소적으로 보완할 여지가 있다. 마지막 답변은 여러 경험이 설명·이해 역량의 근거를 이루며, 같은 사건의 연속이나 일대일 인과관계를 반드시 요구한 초기 지적은 과했다. 사례 비중 조정은 선택적 개선이다.

따라서 초기 예상과의 불일치를 곧 검토 실패로 집계하지 않는다. 원문 검토 결과와 사전 가설은 그대로 보존하고, 이 사후 판단을 구분해 기록했다. 추가 규칙이나 사례별 탐지 조건은 넣지 않았다. 문서 중복과 활용 요구 충돌의 해소는 확인했으나, 새 초안의 품질 향상이나 누락 방지를 입증한 것은 아니다.

새 검토자, 문서, 입력 범위가 함께 달라진 관찰 비교다. 단일 변경의 인과 효과, 생성 품질 개선, 다른 모델·환경의 성능은 검증하지 않았다. 정상/결함 대조 사례도 소수이며 최종 수정안의 실제 초안 검토는 1회다. 성공할 때까지 같은 결함을 암시하며 재실행하지 않았다.
