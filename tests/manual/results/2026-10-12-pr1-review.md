- 실제 지원 자료와 외부 서비스 데이터는 변경하지 않았다.

## 수정한 문제

1. 상대 경로로 조사 결과를 검사하면 완료한 외부 동기화를 pending으로 오판했다. 대상과 스냅샷의 경로를 정규화했다.
2. 실제 검사 전에 검사 완료 플래그가 필요했다. 체크포인트 없는 본문 사전 검사 `--body-only`를 추가했다. 최종 검사도 미완료 기록의 오류와 실제 본문 검사 결과를 함께 반환한다.
3. 설계의 경험형·성찰·작성 여부를 작성본에서 바꾸어도 조건 불일치를 검사하지 않았다. 설계를 먼저 갱신하도록 비교한다.
4. 새 읽기 점검을 작성본에서 누락하거나 false로 바꾸면 최종 후보 검사를 생략할 수 있었다. 설계의 요구도 검사하고 양쪽 새 양식에 표시한다.
5. 미해결 권장 문제가 있어도 final_candidate가 통과했다. 일반 초안은 허용하고 최종 후보는 거부한다.
6. 직접 호출한 검사 함수는 규칙 파일의 min/max를 자동 적용하지 않았다. CLI와 같은 제한을 적용하며 명시적 제한을 우선한다.
7. 손상된 문서가 다중 조사 집계를 중단하거나, 잘못된 문항 구조가 표현 검사에서 예외를 일으킬 수 있었다. 오류 결과로 반환하고 나머지 조사 대상도 집계한다.
8. 작성 지침이 결과의 필수 시험 조건까지 제외하고, 이후 행동 변화·회사 고유성·결말을 불필요하게 강제했다. 정확성에 필요한 조건은 유지하고 문항과 확인된 사실에 따라 적용하도록 통일했다. 작성자에게 JD·기업 사실과 역할·범위 조건도 전달한다.
9. 본문을 원본보다 먼저 읽는 검토 순서, 실제 검사 후 기록, 판정 변경의 이유 기록을 지침·양식·예시에 맞췄다. 훅 제거 시 다른 설정을 보존하도록 안내했다.

## 검증 범위의 한계

자동 검사는 문항 ID·기록·형식·분량·인용 위치와 상태 일치를 확인한다. 사실 출처의 진실성, 소재 적합성, 문맥과 문장 완성도를 자동 보증하지 않는다. 문서 수정은 지침 간 대조로 확인했다. 새로운 대화·모델·환경에서 실제 초안을 생성하는 수동 품질 평가와 Windows 실행은 이번 로컬 검증에서 미실행이다. GitHub CI의 이전 성공을 수정본의 결과로 취급하지 않는다.
