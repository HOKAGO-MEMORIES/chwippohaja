# 예시 답변

작성 패스에서 문장의 구조와 리듬을 참고하는 예시다. 모든 예시는 **가상 사실**로 쓰였다. 실제 지원자의 경험이 아니며, 사실이나 문장을 가져다 쓰지 않는다. 실제 지원자가 채택한 좋은 답변은 워크스페이스의 `공통자료/자소서_좋은예시.md`에 모은다.

예시는 실제로 제출된 좋은 답변들에서 공통으로 보인 특징을 가상 소재로 다시 쓴 것이다.

| 파일 | 문항 유형 | 볼 지점 |
| --- | --- | --- |
| [성장과정](성장과정.md) | 성장, 영향을 준 사건 | 장면으로 세운 전환점, 도입과 맞물리는 결말 |
| [원칙](원칙.md) | 원칙, 기준 준수 | 쉬운 선택과 판단을 한 문장씩 맞세우기 |
| [협업](협업.md) | 의견 차이, 조율 | 내 판단이 틀린 지점을 인정하는 흐름 |
| [AI활용](AI활용.md) | AI 활용, 사회 이슈 견해 | AI가 한 일과 내가 한 일을 주어로 나누기 |
| [지원동기](지원동기.md) | 지원동기, 입사 후 포부 | 확인된 회사 업무·서비스와 경험의 연결 |
| [피할 문체](피할-문체.md) | 공통 | 자주 나오는 약점과 고친 문장 |

문장 구성과 결말의 선택 기준은 [문장 쓰기](../../references/essay-craft.md)를 따른다. 위 표와 각 예시의 해설은 해당 답변에서 선택한 구조가 어떻게 작동하는지 설명한다. 판단 문장, 대안 비교, 태도나 다음 행동으로 닫는 결말을 모든 답변의 필수 요소로 삼지 않는다.
