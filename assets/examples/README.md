# 예시 답변

작성 패스에서 문장의 구조와 리듬을 참고하는 예시다. 모든 예시는 **가상 사실**로 쓰였다. 실제 지원자의 경험이 아니며, 사실이나 문장을 가져다 쓰지 않는다. 실제 지원자가 채택한 좋은 답변은 워크스페이스의 `공통자료/자소서_좋은예시.md`에 모은다.

예시는 실제로 제출된 좋은 답변들에서 공통으로 보인 특징을 가상 소재로 다시 쓴 것이다.

## 좋은 답변의 공통점

1. **첫 문장이 답이다.** 회사 소개, 가치 인용, 배경 설명으로 시작하지 않는다.
2. **판단 문장이 하나 있다.** "~보다 ~이 우선이라고 판단했습니다", "~하면 ~하기 때문입니다". 경험의 나열은 이 판단의 근거다.
3. **전환점이 짧다.** "그런데", "하지만", "~습니다만", "그때 떠오른 것이 ~였습니다" 같은 짧은 문장이나 접속 표현으로 장면이 바뀐다.
4. **1인칭으로 본 것을 쓴다.** 칭찬이나 평가 대신 직접 써 보고 겪은 일을 쓴다. "눈에 들어왔습니다", "실감했습니다"처럼 절제된 느낌 표현이 보고서체를 덜어 준다.
5. **숫자는 한두 개다.** 판단 이유나 결과의 크기를 설명하는 숫자만 남긴다.
6. **결말이 도입을 다시 받는다.** 첫 문단의 문제의식으로 돌아가 이 경험에서 생긴 태도나 다음 행동 하나로 닫는다.
