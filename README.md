# chwippohaja

한국 취업 지원을 공고 등록부터 최종 제출 자료 정리까지 이어서 관리하는 Codex 스킬입니다.

로컬 파일은 사실과 작성 원본으로 사용하고, Google Drive는 동기화와 파일 링크, Notion은 공고와 지원 상태의 인덱스로 사용합니다. 계정 ID와 개인 자료를 저장소에 넣지 않고 실행 시점에 현재 워크스페이스와 연결 서비스를 발견합니다.

## 지원 범위

- 공고와 JD 보관
- 공식 자료를 바탕으로 한 기업 리서치
- 같은 기업의 여러 공고와 공고 변경 이력 관리
- 지원 건 폴더 생성과 작성 번호 계산
- 회사별 작업 폴더 생성
- 지원서 입력 항목과 증빙 정리
- 자소서 소재 수집, 초안, 리뷰와 버전 관리
- 선택적인 `humanize-korean` 윤문
- Drive 파일 링크 확인
- Notion 지원 단계와 주요 링크 관리
- 실제 제출 PDF 보관

## 설치

저장소를 Codex 스킬 디렉터리에 복사하거나 심볼릭 링크로 연결합니다.

macOS와 Linux:

```bash
git clone https://github.com/<GitHub 사용자명>/chwippohaja.git
mkdir -p ~/.codex/skills
ln -s "$(pwd)/chwippohaja" ~/.codex/skills/chwippohaja
```

Windows에서는 저장소를 `%USERPROFILE%\.codex\skills\chwippohaja`에 복사하거나 디렉터리 연결로 추가합니다.

## 처음 시작

새 Codex 작업에서 다음처럼 요청합니다.

```text
$chwippohaja로 처음 설정해줘.
```

스킬은 기존 워크스페이스를 먼저 찾습니다. 없으면 다음 항목을 순서대로 선택합니다.

1. 로컬 폴더 또는 Google Drive 동기화 폴더
2. 자동으로 발견한 경로 후보 또는 사용자가 지정한 경로
3. 활성 시즌 이름
4. Google Drive와 Notion 연결 기능 사용 여부

생성 계획을 확인한 뒤 승인하면 공통자료, 작성템플릿, 증빙서류, 시즌 폴더와 운영 규칙을 만듭니다. 기존 파일은 덮어쓰지 않습니다.

환경 설정 뒤에는 개인 사실을 준비하는 방식을 선택합니다.

1. 사용자가 선택한 기존 이력서 또는 포트폴리오에서 가져오기
2. 학력, 경력, 프로젝트와 기술을 한 영역씩 질문하며 정리하기
3. 정보 정리는 건너뛰고 첫 공고부터 등록하기

가져온 내용은 후보로 먼저 보여주며 사용자가 확인한 사실만 공통자료에 기록합니다. 건너뛰어도 공고와 JD 정리는 가능하지만, 이력서와 자소서 작성 전에는 필요한 사실을 확인합니다.

Codex에서 다음처럼 사용합니다.

```text
$chwippohaja로 이 공고를 등록하고 지원 준비를 시작해줘.
$chwippohaja로 기존 회사 자소서 작성 단계부터 이어서 진행해줘.
$chwippohaja로 제출한 PDF를 보관하고 Notion을 지원 완료로 바꿔줘.
```

## 실행 환경

- 온보딩에서 생성하거나 가져온 워크스페이스
- 현재 작업 폴더의 `AGENTS.md`와 운영 규칙
- 개인 사실을 저장한 공통자료
- `.chwippohaja/workspace.json`의 정보 설정 상태
- 회사별 작업 폴더
- Notion 연결 기능
- Google Drive 연결 기능
- 선택 사항: `humanize-korean`

Notion과 Google Drive 연결이 없는 환경에서는 로컬 작성 작업만 수행할 수 있으며, 연결 반영이 필요한 요청은 완료로 처리하지 않습니다.

Notion에 기존 지원 관리 데이터베이스가 없으면 사용자가 선택한 페이지에 새 데이터베이스를 만드는 계획을 먼저 보여줍니다. 사용자가 승인한 경우에만 생성하고 실제 읽기와 쓰기 권한을 확인한 뒤 연결 상태를 갱신합니다.

## 개인정보

이 저장소에는 다음 값을 커밋하지 않습니다.

- 토큰, 쿠키와 OAuth 인증 파일
- 실제 Notion 페이지와 데이터베이스 ID
- 실제 Drive 파일과 폴더 ID
- 계정 이메일과 로컬 절대 경로
- 이력서, 자소서, 성적표와 증빙서류

로컬 전용 설정과 임시 윤문 결과는 `.gitignore`로 제외합니다.

## 개발 확인

온보딩과 글자 수 계산 도구는 Python 표준 라이브러리만 사용합니다. 변경 후 macOS와 Windows에서 같은 테스트를 실행합니다.

```bash
python -m unittest discover -s tests -v
```
